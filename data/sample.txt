Machine learning is the study of algorithms that improve their performance on a task through experience. Instead of writing explicit rules, we choose a family of models, define a loss function that measures how wrong a model is, and use optimization to find parameters that make the loss small on training data. The central question of the field is generalization: why does a model that fits the training data also perform well on data it has never seen?

Supervised learning uses labeled examples. A classifier maps inputs to discrete labels, while a regressor predicts continuous values. Unsupervised learning finds structure in unlabeled data, for example by clustering similar points or by learning a compressed representation. Self-supervised learning creates labels from the data itself; predicting the next token in a sentence is a self-supervised objective, and it is the objective used to pretrain large language models.

Neural networks are compositions of simple differentiable functions. Each layer applies a linear transformation followed by a nonlinearity such as ReLU or GELU. Gradients of the loss with respect to every parameter are computed with backpropagation, which is reverse-mode automatic differentiation applied to the computation graph. Stochastic gradient descent and its adaptive variants, such as Adam, then update the parameters in the direction that reduces the loss.

The transformer architecture replaced recurrence with attention. In self-attention, every token produces a query, a key, and a value vector. The attention weight between two tokens is the softmax of the scaled dot product of the query of one token with the key of the other. The output for each token is the weighted sum of value vectors. Multi-head attention runs several of these operations in parallel so the model can attend to different kinds of relationships at the same time. Positional information is injected with learned embeddings, sinusoidal encodings, or rotary embeddings.

Before text reaches a transformer it must be converted to integers. A tokenizer splits text into units called tokens and maps each token to an id in a fixed vocabulary. Character-level tokenizers have tiny vocabularies but produce very long sequences. Word-level tokenizers produce short sequences but cannot represent rare or unseen words. Subword tokenizers such as byte-pair encoding sit between these extremes. Byte-pair encoding starts from individual bytes and repeatedly merges the most frequent adjacent pair into a new token, so common words become single tokens while rare words are split into meaningful pieces.

Large language models are pretrained on enormous text corpora and then adapted to downstream tasks. Full fine-tuning updates every parameter, which is expensive in memory and storage. Parameter-efficient fine-tuning methods, such as low-rank adaptation, freeze the pretrained weights and learn a small number of additional parameters. Retrieval-augmented generation gives a model access to an external knowledge base at inference time, which reduces hallucination and allows knowledge to be updated without retraining.

Evaluating generative models is difficult. Exact match is too strict for free-form answers, so practitioners also use token-level F1, n-gram overlap metrics such as BLEU and ROUGE, embedding similarity, and judgments from humans or from other models. A well-calibrated model should be confident when it is correct and uncertain when it is wrong; expected calibration error measures the gap between confidence and accuracy.

Good research practice matters as much as clever ideas. Fix random seeds, report variance across runs, compare against strong baselines, ablate each component, and keep evaluation data strictly separate from training data. Reproducible code and honest reporting make results trustworthy and allow others to build on them.
